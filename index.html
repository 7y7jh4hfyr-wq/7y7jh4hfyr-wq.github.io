Content Factory — YouTube Publisher

Это служебное приложение для автоматической публикации коротких видео (YouTube Shorts) на собственные каналы владельца аккаунта через YouTube Data API v3.

Приложение работает на личном сервере (content factory). Доступ к Google/YouTube выполняется только после явного согласия пользователя (OAuth 2.0). Приложение не предназначено для публичной регистрации сторонних пользователей.
