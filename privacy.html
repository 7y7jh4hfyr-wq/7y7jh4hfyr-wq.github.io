Политика конфиденциальности

Приложение: Content Factory — YouTube Publisher

Дата вступления в силу: 24 октября 2026 г.

1. Кто мы

Приложение используется владельцем YouTube-каналов для загрузки и управления собственным контентом (видео, заголовки, описания, статус публикации) через официальные API Google.

2. Какие данные обрабатываются

При авторизации через Google OAuth приложение может получать доступ к данным Google/YouTube, необходимым для запрошенных разрешений (scopes), в том числе:

  • идентификатор и название YouTube-канала, связанного с аккаунтом;
  • загрузка видео и обновление метаданных на ваших каналах;
  • при включённой аналитике — агрегированные показатели канала (read-only), если запрошен соответствующий scope.

Мы не запрашиваем пароль Google. OAuth-токены хранятся на защищённом сервере владельца (не в этом репозитории и не на GitHub Pages).

3. Цель использования

Данные используются только для автоматизации публикации и сопровождения собственных роликов на YouTube. Данные не продаются и не передаются третьим лицам для рекламы или профилирования.

4. Хранение и удаление

Токены доступа хранятся до отзыва пользователем в настройках аккаунта Google или до удаления приложением. Видеофайлы и метаданные хранятся на инфраструктуре владельца каналов.

5. Безопасность

Доступ к серверу ограничен. Секреты OAuth не публикуются в открытых репозиториях.

6. Контакты

По вопросам конфиденциальности: используйте адрес поддержки, указанный в Google Cloud Console → OAuth consent screen для этого приложения.
