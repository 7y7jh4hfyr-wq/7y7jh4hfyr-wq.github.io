Условия использования

Приложение: Content Factory — YouTube Publisher

Дата: 24 октября 2026 г.

1. Назначение

Приложение предназначено для владельца YouTube-каналов для автоматизации загрузки и управления собственным контентом через YouTube Data API и Google OAuth. Сторонним пользователям сервис не предлагается.

2. Согласие

Подключая Google-аккаунт и используя приложение, вы подтверждаете, что являетесь владельцем или уполномоченным администратором соответствующих каналов и соглашаетесь с этими условиями и политикой конфиденциальности.

3. Ваши обязанности

  • Соблюдать Условия использования YouTube и правила Google API.
  • Не передавать токены доступа третьим лицам.
  • Использовать приложение только для законного контента, на который у вас есть права.

4. Ограничение ответственности

Приложение предоставляется «как есть». Владелец не несёт ответственности за сбои API Google/YouTube, блокировки канала или потерю данных, кроме случаев, прямо предусмотренных применимым законом.

5. Прекращение

Вы можете в любой момент отозвать доступ приложения в настройках Google. Владелец может прекратить работу сервиса без предварительного уведомления.

6. Контакты

Вопросы: адрес поддержки, указанный в Google Cloud Console → OAuth consent screen.
